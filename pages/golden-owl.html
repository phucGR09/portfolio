Overview

The project was a full-stack Applicant Tracking System. I worked across application layers to turn a hiring workflow into a structured product that teams could use and extend.

  • Collaborated across frontend and backend layers.
  • Organized applicant and hiring data around relational design principles.
  • Built a foundation for secure, role-aware workflows.

Production

Production work focused on dependable workflows, clear API boundaries, and operational visibility.

  • Designed and implemented a scalable PostgreSQL database.
  • Developed RESTful APIs with Node.js.
  • Added JWT and OAuth authentication with role-based access control.
  • Documented endpoints with Swagger for team collaboration.
  • Deployed the application manually on AWS and monitored errors with Sentry.
